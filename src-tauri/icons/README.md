# Custom application icon

Generated with the built-in image generation tool on 2026-11-01. Source: `app-icon-generated.png`.
Packaged PNG / ICNS / ICO assets are derived from that source with macOS `sips`, `iconutil` and Pillow's ICO encoder.
The monochrome menu bar template is the separate editable `tray.svg`; `tray.rgba` is its 32×32 RGBA raster.

Generation prompt:

> Use case: logo-brand. Asset: finished macOS application icon for a small personal agent routing dashboard named Magpie, no text. Create one icon only, centered square 1024x1024 canvas. Transparent outside a large rounded-square charcoal tile occupying about 86% of canvas with macOS app-icon corner curvature. No white outer border, no frame or mockup, no devices or background scenery. Inside the tile an exceptionally clean, bold, elegant geometric Eurasian magpie bird mark: pearl-white head and shoulder, dark graphite body, one large wing with a subtle restrained teal-to-slate iridescence, long diagonal tail, a tiny beak and small black eye. The bird should read instantly at 32 pixels. Use just a few strong smooth shapes, expert vector-like design, no feather detail, no lettering, no letter M, no mountain shape, no pink. A slight soft tonal gradient on charcoal tile is acceptable, overall refined matte dark macOS utility aesthetic with excellent silhouette. Entire tile and full bird in frame, generous optical balance. Genuinely transparent exterior.
